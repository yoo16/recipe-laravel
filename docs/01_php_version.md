# PHP バージョンとアップグレードについて

## 結論

**この教材は PHP 8.3 以上が必須。** PHP 8.2 以下の人は、授業までに PHP を 8.3 以上へ上げること。

## フレームワークと必要な PHP

| Laravel | 必要な PHP |
|---------|-----------|
| 13（本教材） | 8.3 以上 |
| 11 / 12 | 8.2 以上 |
| 10 | 8.1 以上 |

PHP が足りないと `composer install` / `composer create-project` の時点で失敗する。

## なぜ上げる必要があるのか（セキュリティ）

PHP は各バージョンに**サポート期限**があり、期限が切れると脆弱性が見つかっても**修正版が出ない**。

| PHP | 状態（2026-11 時点・要再確認） |
|-----|------------------------------|
| 8.1 | セキュリティサポート終了（2025 年末）。**使用しない** |
| 8.2 | セキュリティサポートが 2026 年末で終了予定。**もうすぐ切れる** |
| 8.3 | 2027 年末までセキュリティサポート |
| 8.4 以降 | より長くサポート |

- サポート切れの PHP を使い続けると、既知の脆弱性が放置される。Web アプリは外部からの入力を受けるため、影響を受けやすい。
- Laravel 本体や Breeze / Inertia などのライブラリも、古い PHP を順次切り捨てる。古い環境に留まるほど、最新の教材・パッケージが使えなくなる。
- 「授業が終わったら使わない」環境でも、そのまま本番や個人開発に流用しがち。最初から新しい環境に揃えておく。

> 最新のサポート期限は必ず公式で確認すること: https://www.php.net/supported-versions.php

## 自分の PHP バージョンを確認する

```bash
php -v
```

`PHP 8.3.x` 以上ならそのまま次へ進める（`02_setup.md`）。

## アップグレードの例

環境によって手順が違うため、方針のみ記載。詳細は各自の環境に合わせて確認する。

- **Mac（Homebrew）**: `brew update && brew upgrade php`（複数バージョン運用なら `brew install php@8.3`）
- **Windows**: 使用中の環境（XAMPP / Laragon / Herd など）を PHP 8.3 以上が同梱された最新版に更新する
- **Docker**: イメージのタグを `php:8.3` 以上にする

アップグレード後は `php -v` と `composer --version` を再確認する。

## 授業前チェックリスト

- [ ] `php -v` が 8.3 以上
- [ ] `composer --version` が動く
- [ ] `node -v` / `npm -v` が動く
- [ ] `php -m` に `sqlite3` / `pdo_sqlite` が含まれる
